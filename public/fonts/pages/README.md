# Website Pages fonts

Self-hosted (not linked from Google Fonts) so a public Website Page never sends
its readers' addresses to a third party, and keeps working offline. Latin
subset, variable weights, normal + italic. Used only by the page render
(`src/modules/website-pages/lib/theme.ts`).

All four families are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which permits bundling and redistribution:

- Public Sans: USWDS / General Services Administration
- Montserrat: The Montserrat Project Authors
- Figtree: The Figtree Project Authors (Erik Kennedy)
- Source Serif 4: Adobe

Downloaded 2026-09-28 from the Google Fonts CSS2 API (the `latin` blocks).
